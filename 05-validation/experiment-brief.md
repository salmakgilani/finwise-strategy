# The Validation · FinWise

> Module 5 · Experimentation Methods. The experiment brief that tests the bet.

## Method

**Method:** A/B test

**Why:** Onboarding can be randomized per user, and ~490 trials a month gives a clear result in about 8 weeks.

_____

## Hypothesis + primary metric

If we replace the current onboarding with the 4-screen answer-first flow, more new trial users will import data and reach their first modeling output within 7 days.

**Primary metric:** % of new trial users who import data and reach their first modeling output within 7 days, target: +10 points over control

_Experiment: Answer-first onboarding, A/B test 50/50_

_Testing the 4-screen onboarding on new trial signups. Current experience: full access from day 1 with no guided path._

_Predicted outcome: more users reach a first modeling output, and faster. If successful: roll out with a small holdout to track conversion. If unsuccessful: check which screen users drop off at._

_____

## Guardrail + read date

- **Guardrail:** Onboarding completion doesn't drop more than 5 points vs. control.
- **Read date:** 8 weeks after launch
